# Portofolio DevOps

Website portofolio profesional untuk Muhammad Sultan Ihsan, menonjolkan keahlian DevOps, IT Support, dan Cloud Infrastructure.

## Teknologi

- React + Vite
- CSS biasa, tanpa Tailwind CSS
- Docker multi-stage build
- Nginx untuk serve static build
- Docker Compose dengan `restart: always`

## Deployment

Service berjalan pada port lokal `8085` melalui Docker Compose.
