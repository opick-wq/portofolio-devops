# Portofolio DevOps

Website portofolio profesional untuk menonjolkan profil Muhammad Sultan Ihsan sebagai DevOps Engineer, IT Support, dan Cloud Infrastructure specialist.

## Fitur

- React + Vite
- CSS biasa, tanpa Tailwind CSS
- Responsive design
- Konten DevOps, IT Support, AWS, Docker, Ansible, Terraform, Jenkins, Prometheus, Grafana
- Dockerfile production dengan Nginx
- Docker Compose dengan `restart: always`
- Port lokal: `8085`

## Deployment

```bash
docker compose up -d
```

Akses lokal:

```text
http://localhost:8085
```
